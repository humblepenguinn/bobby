![Bobby Banner](assets/banner.jpg)

A tiny desktop app that hooks into your Google Calendar for event reminders and calls you out whenever you're idle for too long.

https://github.com/user-attachments/assets/73b63df2-73e6-4e22-89cd-0908b2946c16

## Getting Started

```bash
# Install dependencies
make install

# Run Bobby
make run
```

## Autostart

```bash
# Enable autostart on desktop login
make enable-autostart

# Disable autostart
make disable-autostart
```
